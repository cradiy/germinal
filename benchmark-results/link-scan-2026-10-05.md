# Visible link scanning: 2026-10-05

Before: release revision `a2672d5`. After: deferred width calculation in
visible-link discovery and skipping plain-URI detection when no visible colon
exists. Explicit OSC 8 labels do not require a visible colon and remain exported.
Width calculation, supported schemes, punctuation trimming, soft-wrap handling,
and explicit-link precedence otherwise use the existing implementation.

Only confirmed link characters need widths. Removing widths from temporary
visible-character records also reduces their payload. This change adds no
persistent cache.

## Measurement

AMD Ryzen AI 7 H 350, Rust 1.98.0, release builds, JetBrainsMono Nerd Font size 20,
142x40 cells, 10,000 scrollback lines, ligatures off. Three paired repetitions,
100 excluded warm-up frames and 5,000 measured frames each. Before/after order
alternated by repetition. No builds or tests ran concurrently with measurements.
DISPLAY and WAYLAND_DISPLAY were unset; no windows or GPU devices were created.

```sh
env -u DISPLAY -u WAYLAND_DISPLAY target/release/examples/terminal_headless_benchmark \
    --profile unicode-unique --frames 5000 --repeats 1
```

The same command ran for ascii, unicode-repeated, unicode-unique, and links.
Before binary: `/tmp/germinal-headless-before-link-width`.
Individual samples and all CPU-stage timings: [CSV](link-scan-2026-10-05.csv).

Median link-discovery time, microseconds per frame:

| Profile | Before | After | Reduction |
|---|---:|---:|---:|
| ASCII | 25.242 | 17.328 | 31.4% |
| Repeated Unicode | 24.742 | 17.122 | 30.8% |
| Unique Unicode | 23.768 | 16.128 | 32.1% |
| Plain URLs and OSC 8 | 45.722 | 42.672 | 6.7% |

These percentages apply only to link discovery, not overall terminal CPU or
displayed FPS. The grid is still scanned. Non-link text containing colons cannot
use the no-colon shortcut. Link-dense content still requires width calculations.
CPU frequency and desktop background activity are uncontrolled.

## Validation

Workspace format/check/tests and all-target/all-feature Clippy with warnings
denied passed: 616 tests passed, one ignored. The added regression checks exact
hit regions for a wide-character URL spanning rows, an OSC 8 label with Chinese
and a combining mark but no colon, and stale-link removal after clearing.
Existing tests cover punctuation, explicit-link precedence, and worker export.

All new runtime measurements were headless. Mouse hover/click and compositor
visual acceptance remain unverified in this round to avoid desktop interruption.
